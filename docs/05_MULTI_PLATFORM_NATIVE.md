# 📱 Danphe-Web: बहु-प्लेटफर्म र नेटिभ वास्तुकला (Multi-Platform Native Guide)

> **एकल कोडबेस (Single Codebase) • वेब DOM • एन्ड्रोइड २४-बाइट बाइनरी (`.dolp`) • इम्बेडेड C++ / LVGL (ESP32/STM32)**

---

## १. एकल कोडबेस, असीमित प्लेटफर्म (Write Once, Run Everywhere)

डाँफे इकोसिस्टमको सबैभन्दा शक्तिशाली पक्ष भनेको **एकल साझा JSX दृश्य (Single Universal JSX View)** हो। तपाईंले लेख्नुभएको `app.jsx` र कम्पोनेन्टहरू ३ वटा फरक-फरक प्लेटफर्ममा बिना कुनै परिवर्तन चल्दछन्:

```
                  ┌───────────────────────────────┐
                  │      Shared JSX Components    │
                  │    (components/, pages/, app) │
                  └──────────────┬────────────────┘
                                 │
                 ┌───────────────┼───────────────┐
                 ▼               ▼               ▼
         ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
         │   वेब DOM    │ │ एन्ड्रोइड SDK│ │ इम्बेडेड C++ │
         │  (Danphe-Web)│ │ (.dolp 24B)  │ │ (LVGL/ESP32) │
         └──────────────┘ └──────────────┘ └──────────────┘
```

## २. तीनै प्लेटफर्ममा कसरी कम्पाइल हुन्छ? (Compiler Targets)

डाँफे कम्पाइलर पाइपलाइनले लक्ष्य (Target) अनुसार फरक-फरक आउटपुट उत्पादन गर्छ:

### क. वेब लक्ष्य (Web Target):
* **कम्पाइलर:** `DanpheCodeGenerator.toWebJS()`
* **आउटपुट:** शुद्ध जाभास्क्रिप्ट, प्रत्यक्ष DOM पोइन्टर, र < ६ KB बन्डल।
* **गति:** ब्राउजरमा भर्चुअल DOM डिफिङ बिना `< १ µs` लेटन्सी।

### ख. एन्ड्रोइड नेटिभ लक्ष्य (Android Native Target):
* **कम्पाइलर:** `TitanCompiler.js` र `BinaryEmitter.js`
* **आउटपुट:** **२४-बाइट बाइनरी इन्स्ट्रक्सन स्ट्रिम (`.dolp`)** र पूर्ण एन्ड्रोइड APK (`DanpheNative.apk`)।
* **विशेषता:** कुनै जावास्क्रिप्ट इन्जिन चाहिँदैन; Kotlin/C++ को `BinaryParser.kt` ले सिधै बाइनरी बाइटकोड पढेर नेटिभ भ्यू बनाउँछ।
* **बूट लेटन्सी:** ० मिलिसेकेन्ड (तत्काल खुल्छ)।

### ग. इम्बेडेड हार्डवेयर लक्ष्य (Embedded C++ / LVGL Target):
* **कम्पाइलर:** `TitanLvglCompiler.js`
* **आउटपुट:** माइक्रोकन्ट्रोलर (ESP32-S3, STM32, Raspberry Pi Pico) का लागि C++ LVGL हेडर र स्ट्रक्चर।

```cpp
// स्वतः कम्पाइल भएको C++ LVGL कोड:
lv_obj_t * card = lv_obj_create(lv_scr_act());
lv_obj_set_size(card, 280, 160);
lv_obj_set_style_bg_color(card, lv_color_hex(0x0f172a), 0);
lv_obj_set_style_radius(card, 16, 0);
```

## ३. क्यारियर स्लटहरूको अन्तर-प्लेटफर्म सामर्थ्य (Unified Carrier Slots)

जब तपाईंले घोषणा गर्नुहुन्छ:

```javascript
export const user = reg('user:: name, email, role');
```

* **वेबमा:** `user.name` ले ब्राउजरको DOM इनपुट बाँध्छ।
* **एन्ड्रोइडमा:** `user.name` २४-बाइट बाइनरी फ्रेमको Byte 16..17 (Tx Register) र स्लट १ मा बस्छ।
* **इम्बेडेडमा:** यो सिधै चिपको मेमोरी-म्याप गरिएको बाइनरी ठेगानामा म्याप हुन्छ।

यसले गर्दा एउटै ज्ञान र कोडले वेब, मोबाइल र हार्डवेयर तीनवटै संसारलाई जोड्न सक्छ।
